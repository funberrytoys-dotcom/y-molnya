# 🧲 Y-Молния (Triple Zipper)

**Y-образная трёхсторонняя молния** — концепт на основе исследования MIT (1985 → 2026).  
Патент Уильяма Фримена истёк, идея свободна для коммерческого использования.

> **3 гибкие ленты → застёгиваются → 1 жёсткий стержень**  
> Мгновенный переход «гибкое ↔ жёсткое».

## 📊 Эскизы

| Расстёгнутая (гибкая) | Застёгнутая (жёсткая) |
|---|---|
| 3 ленты свободно висят | Сжимаются в единый стержень |
| Подходит для портфелей, обложек, упаковки | Подходит для подставок, каркасов, фиксации |

---

## 📐 Параметры (предварительные)

- **Размах:** ~150 мм
- **Длина лент:** ~120 мм
- **Ширина ленты:** 20 мм
- **Материалы:** PLA (прочность), TPU (гибкость), PETG (баланс)
- **Цикличность:** 18 000+ застёгиваний (по данным MIT)

## 💼 Применение для ToysBerry (300 FDM)

1. **Фиджет-игрушки** — TikTok-friendly, маржа 10-15×

3. **Упаковка** — складная → объёмная, экономия места 3-5×
4. **Палатки/шелтеры** — сборка за минуты без инструментов
5. **Банный комплекс «БЕРЕГ»** — сумки, коврики, тенты
